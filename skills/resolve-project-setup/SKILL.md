---
name: resolve-project-setup
description: Create a new DaVinci Resolve project with a standard bin structure.
when_to_use: Use when the user is starting a new clip, video, or project.
---

1. Use MCP to verify that Resolve is running and the correct project is open.
2. Create bins: `01_Footage/{A-Roll,B-Roll}`, `02_Sound/{SFX,Music}`, `03_Assets`, `04_Render`, `05_Thumbnails`, and `Edit`.
3. Import footage into A-Roll/B-Roll without modifying the original files.
4. Create a timeline in Edit and report exactly what was created.
