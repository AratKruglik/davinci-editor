# jump-cuts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Новий скіл `jump-cuts`, який оцінює кожну склейку A-roll і дає їй найменше достатнє лікування (лишити, зсунути різ, Smooth Cut, punch-in, порада перекрити), і замінює режим `punch-in` у `tutorial-zooms`.

**Architecture:** Уся логіка рішень живе в одному скрипті `jump_cuts.py`, який працює над одним файлом `<work>/jump/joins.json`; `SKILL.md` лише веде модель кроками й містить виклики Resolve. Модель дає скрипту спостереження з кадрів, скрипт дає рішення й масштаби, Resolve змінюється тільки на копії таймлайна після згоди.

**Tech Stack:** Python 3.10+ стандартна бібліотека; Resolve scripting API через `mcp__DaVinci_Resolve__*`.

**Spec:** `docs/superpowers/specs/2026-11-12-jump-cuts-design.md`

## Global Constraints

- Тільки стандартна бібліотека; чужі хелпери імпортуються через `sys.path.insert`, як у `thumbs.py`.
- Імена інструментів у `.md` пишуться з точним префіксом `mcp__DaVinci_Resolve__`.
- Скрипти не пишуть у медіа-папки; усе під `${user_config.work_dir}/<project>/jump/`.
- Без коментарів, що переказують код (правило користувача); докстрінг модуля з прикладами викликів, як у `zooms.py`.
- `SKILL.md` англійською; `docs/skills/*.md` і README англійською; `docs/*.md` українською.
- JSON результатів змінюють лише команди скрипта, ніколи руками.
- Сегмент коротший за 2 с масштабу не міняє. Запас атаки 0,15 с, запас після слова 2 кадри, зсув не більший за 6 кадрів. Smooth Cut 6 кадрів, потрібен запас ≥ 3 кадри з обох боків. Поріг `jump_diff_threshold` типово 0.02, Smooth Cut нижче 3 × поріг.
- Робота в гілці `jump-cuts`, коміт після кожного завдання.

## Review Focus

1. Таймлайн з одним елементом A-roll або без склейок: `joins` пише порожній список і виходить з кодом 0, `classify` на ньому не падає. Тест у завданні 1 і 2.
2. Вимкнений елемент A-roll або зі швидкістю ≠ 100 %: його склейки отримують `source_change`-подібний пропуск (`skip: "disabled"` / `"speed"`), сегмент зафіксований. Тест у завданні 1.
3. Проміжок між сусідніми елементами A-roll (`left.end != right.start`): це не склейка, у список не потрапляє. Тест у завданні 1.
4. `diff` на кадрах різного розміру або з відсутнім файлом: `SystemExit` з назвою файла, без traceback. Тест у завданні 2.
5. `classify` після `decide`: рішення користувача не перезаписується; `decide --decision punch` для склейки, де обидва сусіди зафіксовані, відмовляє з поясненням. Тест у завданні 2.

## Формат `joins.json`

```json
{"timeline_id": "…", "fps": 25.0, "width": 3840, "height": 2160, "start_frame": 90000,
 "segments": [{"index": 0, "item_id": "…", "clip_id": "…", "start": 90000, "end": 90250,
               "source_start": 120, "left_offset": 120, "right_offset": 900,
               "fixed": null, "scale": 1.0}],
 "joins": [{"id": "j1", "frame": 90250, "left": 0, "right": 1, "removed": "pause", "split": false,
            "covered": false, "source_change": false, "skip": null, "roll_range": [-3, 4], "rolled": false,
            "diff": null, "max_cell": null, "observation": null,
            "auto": null, "decision": null, "reason": ""}]}
```

- `fixed`: `null` | `"short"` | `"transform"` | `"hidden"` | `"disabled"` | `"speed"`.
- `frame`: перший кадр правого сегмента; кадри для експорту: `frame - 1` і `frame`.
- `observation`: `{"blink": null|"left"|"right", "mouth": null|"left"|"right", "pose": "same"|"shifted"|"different", "background": "static"|"moving"}`.
- `auto` / `decision`: `hidden` | `source-change` | `leave` | `roll` | `smooth-cut` | `punch` | `cover`. Чинне рішення: `decision or auto`. Для `roll` поруч лежить `"k": int`.

### Task 1: `joins` і `roll_range`

**Files:**
- Create: `skills/jump-cuts/scripts/jump_cuts.py`

**Interfaces:**
- Consumes: `timeline_map.load`, `timeline_map.find_track`, `timeline_map.source_words` (`skills/resolve-core/scripts/timeline_map.py`); дамп за `resolve-core/reference.md#timeline-dump`.
- Produces:
  - `build_joins(dump: dict, transcripts: dict[str, dict], fixed_transform: set[str] = frozenset(), source_offset: int = 0) -> dict` (формат вище).
  - `roll_range(left_out: int, right_in: int, left_words: list[tuple[int, int]], right_words: list[tuple[int, int]], fps: float) -> list[int] | None`; слова як `(start, end)` у кадрах джерела від початку кліпу; `left_out` виключний.
  - CLI: `joins <dump> --transcripts <dir> [--fixed-transform <item_id> ...] [--source-offset N] --out <joins.json>`.

Правила, які тести мають закріпити:
- Доріжка A-roll шукається за роллю `A-roll` (`find_track(dump, "video", "A-roll")`); перекриття рахується лише від увімкнених елементів на увімкнених відеодоріжках з роллю `B-roll` або `Screen`.
- `covered`: обидва кадри `frame - 1` і `frame` під таким елементом. `fixed: "hidden"`: увесь сегмент під ними.
- `source_change`: різні `clip_id`, або `right.source_start < left.source_start + (left.end - left.start)`.
- `split`: на кадрі склейки є маркер з `customData == "claude:split"`. `removed`: нотатка маркера `claude:cut` на цьому кадрі, інакше `""`. Кадр маркера в дампі відносний: `frame - start_frame`.
- `fixed: "short"`: `end - start < round(2 * fps)`.
- `roll_range`: `k` у `[lo, hi]`, де `lo = max(-6, last_left_end + 2 - left_out, prev_right_end + 2 - right_in)`, `hi = min(6, next_left_start - left_out, first_right_start - round(0.15 * fps) - right_in)`. `last_left_end`: кінець останнього слова, що починається до `left_out`; `next_left_start`: початок першого слова, що починається з `left_out` або пізніше; `prev_right_end`: кінець останнього слова, що закінчується до `right_in` включно; `first_right_start`: початок першого слова, що закінчується після `right_in`. Відсутня межа не обмежує. `None`, якщо `lo > hi`, якщо `lo == hi == 0`, якщо для кліпу немає транскрипту, або якщо склейка `split`, `covered`, `source_change` чи має `skip`.

### Task 2: виміри, сходинки, масштаби

**Files:**
- Modify: `skills/jump-cuts/scripts/jump_cuts.py`
- Modify: `README.md` (блок Development, після рядка `split_edits.py selftest`)
- Modify: `.github/workflows/release.yml` (після рядка `split_edits.py selftest`)

**Interfaces:**
- Consumes: `build_joins` (Task 1); `luma_grid(path) -> (width, height, rows)` і `write_tiff(path, width, height, rgb)` з `skills/thumbnail-frames/scripts/thumbs.py`.
- Produces:
  - `frame_diff(a_path: str, b_path: str) -> dict` → `{"diff": float, "max_cell": float}`; яскравість нормована до 0..1; `max_cell` це найбільша середня різниця серед клітинок сітки 8 × 8.
  - `classify(data: dict, threshold: float, scale: float) -> dict`: ставить `auto`, `reason`, далі викликає `assign_scales`.
  - `assign_scales(data: dict, scale: float) -> None`: пише `segments[i]["scale"]`; `punch`, який неможливо виконати, перетворює на `cover` (в `auto`, або відмовляє, якщо це `decision`).
  - CLI: `diff <a.tif> <b.tif>`; `observe <joins.json> --join ID [--diff X --max-cell Y] [--blink left|right] [--mouth left|right] --pose same|shifted|different --background static|moving`; `classify <joins.json> --threshold T --scale S`; `decide <joins.json> --join ID --decision D [--k N] --scale S`; `rolled <joins.json> --join ID --k N`; `table <joins.json>` (рядки для звіту: id, кадр, removed, diff, чинне рішення, reason).

Сходинки в `classify` (перше, що підійшло; `reason` одним реченням англійською):
1. `covered` → `hidden`. 2. `source_change` або `skip` → `source-change`. Далі потрібне спостереження: якщо `observation is None` і `diff is None`, `classify` виходить з `SystemExit`, назвавши id.
3. `diff < threshold` → `leave`.
4. не `rolled`, `blink` або `mouth` заданий, `roll_range` не `None` → `roll` (без `k`: його ставить `decide --k`).
5. `diff < 3 * threshold`, `pose == "same"`, `background == "static"`, `left.right_offset >= 3`, `right.left_offset >= 3` → `smooth-cut`.
6. обидва сусіди з `fixed is None` → `punch`. 7. інакше `cover`.
Без `diff` (старий Resolve) правило 3 спрацьовує при `pose == "same"` без `blink`/`mouth`, правило 5 ніколи; `reason` закінчується на `(not measured)`.

`assign_scales`: union-find по склейках з чинним рішенням `leave` / `smooth-cut` / `roll`; група зафіксована, якщо в ній є сегмент з `fixed`; прохід зліва направо: перша група ланцюжка 1.0, через `punch` масштаб перемикається між 1.0 і `scale`, через `hidden` / `source-change` / `cover` скидається на 1.0; `punch` між двома групами, які обидві мусять бути 1.0, неможливий. Зафіксована група після `punch` з групи в 1.0 теж робить його неможливим.

`decide`: `--k` обов'язковий і в межах `roll_range` для `roll`, `k != 0`; будь-яке рішення для `covered` / `source_change` склейки, крім їхнього власного, відмовляється. `rolled`: зсуває `left.end`, `right.start`, `right.source_start`, `join.frame` на `k`, міняє офсети (`left.right_offset -= k`, `right.left_offset += k`), ставить `rolled: true`, очищає `diff`, `max_cell`, `observation`, `auto`, `decision`, `k`.
